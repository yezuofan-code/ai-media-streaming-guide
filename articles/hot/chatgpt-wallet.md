# 2026 ChatGPT 钱包上线：Pro 才有的新入口，国内用户卡在哪一步

> 📍 本文首发于 **[AI与流媒体会员指南](https://ai.fanqiangdao.com/hot/chatgpt-wallet/)**，持续更新以原站为准。


11 月 13 日美东周五，OpenAI 把 ChatGPT 钱包推上线了。官方措辞很克制：让 dots 在用户批准后完成购买。中文圈传得更热闹，标题大多写成「AI 替你刷卡」。

先把最要紧的一句话说清：这个功能现在跟国内绝大多数人没有关系。它只对美国 18 岁以上的 Pro 订阅用户开放，绑的必须是美国发行的 Visa、万事达或美国运通卡。人在国内、卡在国内、账单地址在国内，这几条里没有一条能绕过去。

那为什么还值得写一篇。因为它把 ChatGPT 的档位结构又推了一步：Pro 从「额度更大的那一档」，开始变成「有独立入口的那一档」。这个变化直接影响续费怎么选，也决定现在该不该为它多掏钱。

我的判断先摆出来：钱包本身现在不值一分钱；Pro 那笔账要按「你一周要用多少 Codex 和长任务」来算，跟钱包无关。

## ChatGPT 钱包是什么：dot 替你下单，卡号谁也不给

dots 是 OpenAI 在 9 月底开发者大会上推出的一批个人智能体，能在 ChatGPT 里替你记事、查资料、跑多步任务。钱包接的就是它们，三个入口同时开：dots、ChatGPT Work、Codex，agent 都可以发起购买。

一笔钱从想买走到付完，是四步：


把卡加进 ChatGPT 钱包，一次就够了，不用每次都重填
让 dot 去找东西，选定具体商品
结账前在 ChatGPT 里核对三样：买的是什么、总额多少、用哪张卡
用 Face ID 或指纹确认，这一笔才成立


卡号怎么处理，是这套设计里最实在的部分。dot 拿不到你的卡号，商家也拿不到。卡组织给 agent 的是一枚「支付令牌」，里面装的是单笔专用的卡号、安全码和有效期，这笔交易结束就作废。积分照拿，卡片自带的争议申诉也照旧有效——这一点比很多人的预期要好。

商家那边会自动收到履约需要的信息，收货地址、联系人，不用你再填一遍。

收费上，CNBC 引 OpenAI 的说法：上线初期不抽成。后面还打算加消费限额，能按品类和时段做预授权，让 agent 在你划定的框里自己买。这些话都是意向，落到产品里要等版本。

我认为真正值得记的不是「AI 能买东西」，而是这条路线的选择。去年秋天那套 Instant Checkout 要商家接 OpenAI 的协议，推了半年多就转向；钱包反过来走卡组织，商家一行代码都不用改，只要不主动拦。技术上笨一点，落地阻力小得多。这是被现实教育过之后的选择。

## 谁能用：四条门槛，国内用户一条都过不去

| 条件 | 具体要求 | 国内用户 |
| --- | --- | --- |
| 使用地 | 美国境内 | 不满足 |
| 年龄 | 18 岁以上 | 看人 |
| 订阅 | ChatGPT Pro | 要另外买 |
| 支付 | 美国发行的 Visa / 万事达 / 美国运通 | 基本没有 |

四条必须同时成立，缺一条就没有入口。这不是灰度名额的问题，是名单问题：钱包从第一天起就写清了开放范围，没开放的地区连按钮都不会出现。

卡这一条最难过，原因不神秘。国内发的双币卡，BIN 归属在中国，账单地址在中国，发起付款时的出口 IP 又在另一个地方，三者对不上，风控第一道就拦下了。哪怕前面几关侥幸过了，钱包的授权是逐笔生物识别，绑定关系绑在卡组织那一侧，出问题时争议和退款也走卡组织通道。用一套对不上的信息去申诉，等于把自己送上去。

所以这篇文章不写改区、不写怎么弄一张美国卡。不是藏着不讲，是那条路的成本和风险都不划算：为了一个刚上线、还限量的支付功能，去动账号的注册地和支付信息，赌的是整个账号。

## 商家在拦：能付钱，不等于哪都能买

United 航空 11 月 11 日表态，会限制 AI agent 访问它的系统订票，理由是数据安全。Amazon 一直不让外部 agent 在自己平台下单。另一头，Walmart 在跟 Meta 的 Muse 合作，Expedia、Booking 这些旅行平台在跟 OpenAI 谈接入。

这张名单说明的问题很具体：钱包解决的是「怎么付」，没解决「让不让你买」。支付是技术活，接入是商业活。商家怕的不是钱收不到，是比价被 agent 做穿、客服成本全转到自己身上、以及下单那头到底是不是一个真人在点确认。

我认为这一层才是 agentic commerce 的真瓶颈。支付通道今天就能铺开，商家的白名单得一家一家谈，谈的过程里还会出现「接了一半」的状态——机票能查不能订，商品能看不能买。

1.2 亿周活、近 1 亿付费用户（三季度末口径）这个体量，足够让商家认真对待，但也足够让商家警惕。这两件事同时成立，钱包的扩张速度不会像发布会听起来那么快。

看这张表有两个细节容易被忽略。

一是同样叫「代充」，银河 ¥189 和飞行派 ¥59 差了三倍多，交付方式不会是同一种。差价买的是不是「把你自己的号升上去」，只能问客服要一句书面答复，别靠猜。订单页写「代充」两个字，不构成任何承诺。

二是 Pro 这一档的货源。银河和飞行派的 AI 线都停在 Plus，没有 Pro 车位；偶尔能碰到商品名写 Pro 的车位，名字对得上不等于权益对得上——是独立号、是共享、是长期车位还是按月续，下单前必须问清，报价以平台实时标价为准。想走得稳，就按官方那 200 美元自己开，代价是支付这一关得自己过。

回到正题：钱包只挂在 Pro 上，所以「为了钱包升 Pro」这个念头要按掉。钱包对美国以外的用户没有入口，为它多付的钱买不到任何东西。Pro 真正值钱的是三样：更高的用量额度、能跑十几分钟以上的长任务、以及新功能的第一批入口。这三样对国内用户是能用的。

我一般用一条标准判断：一周里有多少小时是让模型连续跑十分钟以上的活。不到两小时，Plus 够用，多花的钱是浪费；超过，Pro 的额度差价才赚得回来。这条标准跟钱包无关，跟你的工作强度有关。

## 避坑清单

- **别为钱包升 Pro。** 钱包对美国以外没有入口，这笔加钱买的是零。要升 Pro，理由是额度，不是那个按钮。
- **「代充」不等于「升级你的号」。** 订单页只写代充两个字，交付可能是新号。下单前问三句：升级还是新号、掉订阅怎么赔、几个工作日完成。
- **拼车省的是钱，让的是归属。** 车位不是你的账号，绑卡、逐笔生物识别这类动作都在账号主手里。想要「钱包」这种要本人授权的功能，只能自己开号。
- **香港节点别试。** 不在服务名单里，不是风控误判，挂上去就是地区限制页。
- **同城不同价先问交付。** 银河 ¥189、飞行派 ¥59，差距三倍，差的是交付方式不是运气。
- **Pro 不等于「更强模型」。** 它给的是额度、长任务和新功能入口，模型本身 Plus 也能用。为「模型更强」升档，是买错东西。
- **商家名单会变。** 今天拦 agent 的，明天可能接入；今天接了的，也可能随时退。别把钱包当成日常购物的主力通道。
- **一切以结算页为准。** 平台报价会调，券后价和活动价跟挂牌价不是一回事，下单那一刻的数字才算数。

## FAQ

### 国内能用 ChatGPT 钱包吗？

现在不能。开放范围写得很硬：美国境内、18 岁以上、ChatGPT Pro 订阅、绑美国发行的 Visa / 万事达 / 美国运通卡，四条同时成立才有入口。国内用户缺的不止一条，而且卡这一条是名单层面的限制，不是换个节点能绕过去的。

### ChatGPT 钱包要收手续费吗？

上线初期不抽成，这是 OpenAI 对 CNBC 的说法。但这句话只描述现在：钱包是支付层，未来按交易抽成或者向商家收费的可能性都摆在那里。真实费率以官方后续公告为准，别拿上线口径当长期承诺。

### 为什么非要美国发行的卡？

三件事要一致：卡的 BIN 归属、账单地址、发起付款的出口 IP。钱包的授权和争议处理都走卡组织通道，卡在哪个国家发行，决定了这笔交易归谁管、出事找谁。用一张归属对不上的卡，风控第一道就过不了，后面的争议也没有落脚点。

### ChatGPT Pro 一个月多少钱，国内怎么开？

官方是每月 200 美元，Plus 是每月 20 美元，以官网定价页为准。国内走平台代充，Pro 的车位很少，报价按平台实时标价；Plus 便宜得多，银河 ¥189/月、飞行派 ¥59/月，两档交付方式不同，下单前问清是不是升级自己的号。

### 合租的号能开钱包吗？

开不了，原因不在技术。钱包要绑定持卡人本人的卡，每一笔都要持卡人用 Face ID 或指纹确认，这套授权绑在账号与卡的关系上。合租车位的账号不在你手里，你既绑不了自己的卡，也没法替账号主做生物识别。这也是我认为合租和独立号会越走越开的原因：功能越往「本人授权」走，共享账号能拿到的东西越少。

### 钱包上线了，代充会涨价吗？

短期看不出来。钱包和订阅是两件事：一个管买东西，一个管用服务，涨价与否取决于 Pro 的供货和汇率，不取决于钱包。真要留意的是 Pro 的供给——需求一上来，车位先紧的是 Pro 这一档。

## 收尾：顺序别弄反

钱包这事，国内用户把它当新闻看就行，别当成购买入口。真正要决策的只有一件：Plus 还是 Pro。按工作量选，不按发布会选——一周里让模型连续跑十分钟以上的时间不到两小时，Plus 足够；超过，Pro 的额度差价才划算。我一般按这个顺序走，先算用量，再看价格，最后才挑平台，因为在用量上省下的钱永远比在报价上抠出来的多。
