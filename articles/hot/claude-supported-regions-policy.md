## 11 月 12 日改的是"资格"，不是"技术"

Anthropic 官网《Supported Regions》政策页上，生效日期写的是 2026 年 11 月 12 日。政策是白名单制：名单上有的国家和地区才能访问，没列上的一律视为不支持。

判定拆成三条线，一条比一条狠：

| 判定维度 | 政策口径 | 落到人身上是什么 |
| --- | --- | --- |
| 人在哪 | 身处不支持地区的个人使用，包括原本受支持实体的用户与员工 | 在深圳、香港、澳门打开 Claude Code 就在红线内；在东京、新加坡打开就合规 |
| 公司注册地 | 在不支持地区注册成立或设总部的实体，及其用户、员工 | 人常驻美国，公司注册在境内，照样不能用 |
| 股权与控制 | 被不支持地区的个人或实体直接、间接多数持股或控制的实体 | 去硅谷套壳注册个主体，实控人在国内，一样受限 |

覆盖范围写得很实：Claude.ai、Claude Code、Cowork 这些应用，API 与开发者平台，以及通过云平台、授权转售商渠道拿到的 Claude 模型。翻译一下，走 AWS 或者找转售商买的 Claude，不会因为换了采购渠道就变成合规。

名单这头，中国大陆、香港、澳门、俄罗斯都不在里面；台湾、新加坡、日本在。政策页有一句容易被跳过的补充：列名国家属地和附属地也算支持，比如波多黎各算美国。

Anthropic 自己的表述是"澄清既有规则"。10 月 8 日那版政策更新公告里写明，针对被不支持地区实体多数持股的公司的限制，去年就已经落地，这回是把执行方式讲清楚。所以别把 11 月 12 日理解成"Claude 当天第一次封香港"。

反过来，香港媒体点出了政策没写清的三处空白：短期出差、旅游的人怎么处理；有没有 VPN 例外；生效当天会不会统一断登录。三条官方都没给明确答复。我的建议是按最严的口径准备，别按最宽松的猜。

## 已经开了的 Pro，会被停吗

使用政策把"违规访问、促成访问、为他人提供访问"列为禁止行为，处理方式是警告、限制、暂停，一直到终止。这是阶梯，不是一律封号。

真正比"人在哪"更容易踩的，是一条很多人没读过的条款。使用政策禁止"转售、代理或以其他方式通过未授权渠道提供 Claude 访问，包括把请求经由消费级订阅转发出去、或伪装产品和客户端身份的服务"。这句话冲着代充、合租车头、API 中转站来的。

合租车位的车头在国内、拿一个个人 Pro 订阅替十几个人转发请求，正好落在这一条上。被处理的顺序通常很固定：车头先没，车位跟着掉，你收到的是"账号异常"。这也是为什么这次风波里，掉了车位的人比掉了自己号的人多得多。

执行手段上，有媒体口径提到后台会留存 30 天安全监控数据，看的是行为规律而不是瞬时 IP，还援引招股书说过去九个月有 5% 到 7% 的收入来自事后被认定违规的客户。这两个数字我没在官方页面上找到对应表述，当二手信息看就行，不影响结论：查得比过去细，方向是确定的。

## 第一步：网络这一环，先掐掉"节点能救账号"的念头

这句话得说直白：节点改变不了"人在哪"这个事实。政策判的是物理位置，不是出口 IP 的归属地。所以看到有平台宣传"专线过地区检测""包过 Anthropic 审核"，先当它是夸张宣传——它顶多解决"能不能连上"，解决不了"有没有资格"。

那机场在这个场景里还有什么用？三个用处，都不是绕行：

一是你人本来就在支持地区（出差、留学、常驻海外），需要一条原生、固定、干净的出口，别让风控把你误判成异常登录。二是过渡期导出数据，把 Projects 里的资料、长对话、常用 prompt 搬下来，这些操作都需要稳定连接。三是换到 ChatGPT、Gemini 这类替代模型时，同样要吃一条干净的出口。

选线只看三个词。原生，指 IP 注册地就是使用地，不是拿别处的段广播过来；固定，指锁定一两个节点别漂移，今天美区明天日区是自找验证；干净，指这条出口没有滥用历史，这项自己验证不了，只能靠线路质量兜底。

香港直接排除。以前排除是因为香港 IP 被封锁，现在更彻底——人在香港这件事本身就落在不支持名单里。

### 路线二：走合规主体，只对少数人成立

真有海外实体的，比如外企在华分支、海外注册的公司、在国外读书的学生，可以继续用，但先过三问：公司注册在哪？总部在哪？实控人是不是不支持地区的个人或实体？

三问里有一条踩线，就不合规，哪怕你人常驻纽约。政策写得很明白，"无论个人是否身处支持地区"这几个字出现过两次。云平台和转售商渠道同样不豁免，阿里云、AWS 上买的 Claude 模型一样受约束。

这条路的现实意义是：如果你是外企员工，别自己偷偷开个人号跑公司数据，走公司 IT 采购的合规席位，出事有合同兜着；个人号被停，你连申诉主体都不是。

### 路线三：开源自建，给数据敏感的场景

代码不能出内网、客户资料不能上云的项目，本地部署开源权重是最稳的答案。代价是硬件和运维，收益是彻底不受地区政策摆布。现在主流开源模型的水平，做代码补全、文档摘要、格式转换这些活已经够用，别指望它顶替旗舰模型的复杂推理。

这条路上有个坑要绕开：低价 API 中转站。它同时踩两条线——转售转发本身就是使用政策禁止的行为，你的 prompt 还会完整经过第三方服务器。省下的那点钱，换来的是数据泄露加账号连坐，不值。

## 已经付出去的年费，怎么止损

先把条款摆出来，Anthropic 消费者条款的原文口径有四条：

- 除条款明确约定或法律强制要求，所有付款不退。
- 自己取消订阅，不退已付费用，但可以继续用到这个付费周期结束。
- 因为违反条款被终止，订阅不退费。
- 反过来，如果 Anthropic 出于其他原因单方面终止你的订阅，按比例退还未使用部分。

还有一条常被误读：7 天无理由取消权只给巴西、墨西哥、韩国、台湾的居民，那是当地法定权利。中国大陆用户不在这条里，别拿它当退款依据。

所以止损的目标不是"要回全款"，是"别再多付一期，把能搬的东西搬走"。我建议按这个顺序做：

1. 先备份。把 Projects 里的文件、长对话、常用 prompt 导出到本地。账号一旦停用，条款里写着 Anthropic 可以选择删除账号关联数据。
2. 关自动续费。消费者条款要求至少在当期结束前 24 小时取消，晚了就自动进下一期，钱不退。
3. 年付的认了，月付的立刻停。已经付掉的年费按条款拿不回来，别为了"用回本"继续往里投时间。
4. 开一张工单留痕。写清"因支持地区政策变更无法继续使用"，申请按比例退款或延期，邮箱是 support@anthropic.com。条款没给这条路明确的退款承诺，但不留痕就一定没戏，留了至少有个答复。
5. 合租、代充的车位找平台售后。银河录像局、飞行派这类多品类平台通常能换品，把预算移到 ChatGPT 或 Gemini 的车位上，比重新找一家陌生车头靠谱。
6. 公司采购的走合同。企业协议里一般有服务变更条款，让采购去谈，比你个人发工单有用。

## 避坑清单

- **"包过地区检测"的车位直接跳过。** 判定依据是人所在地，不是 IP。任何号称能改这个事实的，要么在骗你，要么在替你违反条款。
- **别在生效这一周续年付。** 年付不退是条款写死的，月付随时能停，多花的那几块钱买的是选择权。
- **共享 API key 和低价镜像站都别碰。** 转售转发本身被使用政策点名禁止，你的 prompt 还要经过别人的服务器。
- **公司代码别放个人号。** 个人号被停，申辩主体都没有；真出数据事故，责任在你这侧。
- **"内部白名单""员工通道"是骗局。** 政策是白名单制，但对个人开放的口子只有合规主体这一条，没有第二条。
- **香港节点不用试。** 以前是 IP 被封锁，现在是人在香港本身就不符合资格，两件事叠在一起。
- **别等账号被动停用再备份。** 停用通知往往和登录失败同时到，那时你已经进不去控制台了。

## FAQ

### Claude 11 月 12 日新规生效后，我在国内开的 Pro 会被直接封号吗？

不会在当天批量清号。政策给的是判定标准，执行走使用政策的处罚阶梯：警告、限制、暂停、终止。风险高低取决于账号轨迹——注册信息、支付方式、常用登录位置是否一致。合租车位和代充号的风险明显高于自己开的号，因为车头一次违规会连坐整条车位。

### Claude Pro 年付能退款吗？

按消费者条款原文，除明确约定或法律强制，付款一律不退；自己取消不退，因违规被终止也不退。唯一的空间是 Anthropic 出于非违规原因单方终止时按比例退未使用部分。实操上只能开工单协商，别信任何"包退"承诺。年付一次 $200、折合每月 $17，这笔钱在政策变动期就是纯风险敞口。

### 挂机场节点还能不能继续用 Claude？

能连上不等于有资格。政策判的是物理位置，节点只改变出口 IP，不改变你在哪。人在支持地区（出差、留学、常驻海外）时，一条原生固定的线路是必要的；人在不支持地区，线路再好也只是把违规做得更顺。

### Claude 不能用了，转 ChatGPT 还是 Gemini？

看你的活。编码、跑 agent、要插件生态，ChatGPT Plus 更顺；长文档、资料整理、跟 Google 办公套件打通，Gemini 那套更省事。价格差得不多，ChatGPT Plus 车位在银河录像局是 ¥26.1/月（截至 2026-11-09），先按周试，别按年买。具体选法可以看站内 [ChatGPT Plus 订阅指南](https://ai.fanqiangdao.com/solutions/chatgpt-plus/) 和 [Gemini Advanced 开通指南](https://ai.fanqiangdao.com/solutions/gemini-advanced/)。

### 公司用 Claude API 做的产品要下架吗？

看主体。公司注册地、总部、实控人三条里有一条在不支持地区，就属于政策限制范围，云平台和转售商渠道也不豁免，这种情况该走法务和技术评估，不是换个渠道能解决的。反过来，主体完全在支持地区的，正常用，别用个人订阅转发请求就好。
