# 2026 GPT-6.2 Astra 国内怎么用上：聊天框里没有，Work/Codex 才有，Pro 三档差在 Ultrafast

> 📍 本文首发于 **[AI与流媒体会员指南](https://ai.fanqiangdao.com/hot/gpt-6-2-astra/)**，持续更新以原站为准。


北京时间 11 月 18 日凌晨两点，OpenAI 把 GPT-6.2 的两个型号一起放了出来：旗舰 Astra，日常主力 Sol。官方公告第一句话就限定了范围——只在 ChatGPT Work 和 Codex 里，对 Plus、Pro、Enterprise、Edu 四类用户开放。

这句话值得多读两遍。你不是打开聊天框就能看到新模型，聊天框里那一栏显示的仍然是上一代的名字。想摸到 6.2，得先切到 Work 或 Codex 那个视图，而这两个视图的额度是共用的、按套餐分层的。所以这篇文章不按「新模型有多强」来写，按「你在哪、花多少钱、才用得上它」来写：先看入口和档位的真实差别，再算一遍按量与包月的账，最后才是账号与节点这两道绕不开的门。

## 这次发布改了什么：一场价格重新定位

先把官方给的硬数字摆出来。Astra 在 Agents' Last Exam 上，xhigh 档比上代 GPT-6 Astra 的 max 档高 5.2 分，单任务成本不到上代的一半；放到整条产品线看，官方口径是「单任务成本不到 GPT-6 Astra 的三分之一」。它还是 OpenAI 自评网络安全能力最强的一代，在 ExploitBench Internal Port 上比上代高 22 分。

Sol 的定位完全不一样：官方在 FrontierCode 2.0 上给的说法是「合并就绪的代码改动接近 Astra，成本约五分之一」。第三方测评把差距量化到 0.5 个百分点以内。这句话翻译成采购语言就是——大多数写代码的活，不需要买 Astra。

价格这条线更直接。Astra 从每百万 token 输入 10 美元、输出 50 美元，降到 8 美元和 40 美元，降幅 20%；缓存命中的输入从 1 美元砍到 0.40 美元（均以官网价页为准）。Sol 维持 2 美元和 10 美元不变。一边降价一边维持走量款原价，这是很清楚的挤压式定价：用旗舰降价去抢对价格敏感的高频调用，用 Sol 守住日常盘子。

有一个必须写进来的反面数据。独立评测机构 Artificial Analysis 的智能指数给 Astra 62 分，排第二，第一是 Claude Fable 5.2 的 65 分；但在它的编程代理指数上，Astra 相对 GPT-6 Astra 几乎原地踏步，Sol 还比 GPT-6.1 Sol 低了三个百分点，报告里直接写了「编程领域的进展已陷入停滞」。官方的 Agents' Last Exam 偏多步推理和指令遵循，第三方的编程代理指数更贴近真实开发，两组数字都是真的，量的不是同一件事。我认为这才是选型时最该带上的那条信息：别把跑分当能力证明，把它当议价依据。

还有一条多数报道放在末尾的消息：Astra 是 OpenAI 第一个对外发布、被自己判定「达到 AI 自我改进高风险阈值」的模型，配套上线了名为 Control Room 的管控系统，同时对高风险网络安全请求收紧了拒答边界。这条对个人用户影响不大，但公司采购要过合规的，权限边界、日志审计、人工接管这三项得提前问清楚。

表里三处容易误读，逐条说。

第一，聊天框和 Work/Codex 是两套模型池。6.2 只进了 Work 和 Codex，普通 Chat 里 Pro 及以上拿到的是 GPT-6 Pro，由 GPT-6 Astra 驱动，不是这次的 Astra 6.2。很多人升级完 Pro，在聊天框里试了半天，得出「没感觉」的结论，其实是走错了入口。

第二，Free 和 Go 不在这次公告的名单里。这两个档位本身是有 Work/Codex 入口的，只是本次 6.2 的开放范围官方只列了 Plus、Pro、Enterprise、Edu 四类。名单外的档位什么时候跟上，官方没说，别把「没写」当成「永久不给」。

第三，Work 和 Codex 的额度是同一份。上午在 Work 里生成一份四十页的调研报告，下午 Codex 的窗口就少了一截；Plus 和 Pro 上，Excel、PowerPoint、Word 这几个 Office 插件也从这份额度里扣。这条是排产计划里最容易翻车的地方——你以为省下的是两份额度，其实是一份。

## Pro 三档的钱怎么算：差在最后一公里

| 档位 | 月费 | 含 API 额度 | Ultrafast | 适合谁 |
| --- | --- | --- | --- | --- |
| Plus | 20 美元 | 无 | 无 | 每天用一两小时、偶尔跑长任务 |
| Pro 100 | 100 美元 | 100 美元 | 无 | Work/Codex 天天断档、但不需要极速 |
| Pro 200 | 200 美元 | 200 美元 | 只有 Sol | 想要极速、又只在写代码时用 |
| Pro 500 | 500 美元 | 500 美元 | Astra 与 Sol 都有 | 全天跑 agent、或者要给交付物卡时间 |

三个 Pro 档都是月付，不能年付、不能预存几个月。这一点对国内用户反而友好，试错成本锁在一个月里。

真正拉开差距的是 Ultrafast。它是 OpenAI 现在的最高速度档，官方口径是最快约 4.5 倍速，但代价写在计费里：从套餐额度里扣的时候按标准档的 6 倍算，用购买的 credits 或企业按量付费时，2027 年 2 月 28 日前按 3 倍促销价，3 月 1 日起回到 6 倍（太平洋时间，以官网价页为准）。这条规则决定了 Ultrafast 的用法——它不是「让日常工作变快」的开关，是「这次交付不能等」的应急档，日常挂着跑等于自己把额度除以六。

我建议的选法是先看断档频率，不看速度。一周里 Work 或 Codex 撞两三次上限的，Pro 100 就够；天天撞、且任务以写代码为主，Pro 200 的 Sol 极速是合理升级；只有交付物本身在跟时间赛跑，Astra 的极速才值那 300 美元的差价。反过来说，如果你的活是「想清楚再写」，速度根本不是瓶颈，多花钱买的是心理安慰。

还有一个被低估的细节：三个 Pro 档都包含等额 API 额度，$100、$200、$500，绑定一个 API 组织就能领。这意味着 Pro 用户天然有两个模型的调用权——订阅里跑交互，额度里跑脚本和批处理，不用另外开一个 API 账户充值。

## 按量还是包月：拿一个任务算一遍

找一个中等规模的代码任务做基准：输入 10 万 token（一个中等仓库的相关文件加日志），输出 2 万 token。

全走 Astra：0.1 × 8 + 0.02 × 40 = 1.60 美元一次。全走 Sol：0.1 × 2 + 0.02 × 10 = 0.40 美元一次（单价以官网价页为准）。

差四倍。按一天 100 次、一个月 30 天算，Astra 是 4800 美元，Sol 是 1200 美元，中间差出一台不错的开发机。而第三方给这两者编程能力的差距是 0.5 个百分点以内。所以我一律先跑 Sol，等它具体卡在哪一步、卡了两次以上，才把那一类任务单独提到 Astra。

再看额度能换多少 token。Pro 100 含的 100 美元额度，全按 Astra 算是 1250 万输入 token，或者 250 万输出 token；换成 Sol 就是 5000 万输入、1000 万输出。数字摆在一起就明白为什么说 Sol 是这代的性价比锚点——同样的钱，Sol 能跑的活是 Astra 的四到五倍。

缓存那条也值得单独提。Astra 的缓存输入是 0.40 美元每百万，比上代的 1 美元降了 60%（以官网价页为准）。对固定 system prompt、固定代码库上下文的批处理流水线，缓存命中率决定了实际单价，这一项降得比标价降得狠。写脚本的人应该先把 prompt 结构改成「固定部分在前、变量在后」，再谈换不换模型。

Ultrafast 的账要单独算一遍，很多人会算错。同一个任务走 Astra 的 Ultrafast，从套餐额度里扣的等效成本是 6 倍，也就是 9.60 美元一次的量级（计费倍率以官网价页为准）。它换来的是一段等待时间从几分钟压到一分钟上下。值不值，取决于你一小时值多少钱，而不是模型本身。

## 第一步：网络这环，Ultrafast 认的是美国境内推理

这次多了一条以前没有的硬门槛：Ultrafast 要求推理在美国境内完成。也就是说，你挂的节点如果不在美国，这一档要么拿不到，要么直接被降回标准速度。这不是风控脾气，是产品的地理约束，换机场没用，只能换线路落点。

除此之外的老规矩一条没变。香港节点直接排除，OpenAI 不对香港开放服务，挂上去打开就是地区限制页，试也没用。节点要稳，别今天美国明天新加坡，账号被判定为异常流动，轻则反复人机验证，重则要求重新认证。机房 IP 段的纯净度自己验不了，只能靠线路质量兜底，这也是为什么我建议先买一个月验证，别一上来年付。

## 避坑清单

- **聊天框里找不到 6.2，不是买错了。** 6.2 只在 Work 和 Codex，普通 Chat 里 Pro 及以上用的是 GPT-6 Pro，由 Astra 驱动但不是 6.2。
- **Ultrafast 按 6 倍扣额度。** 它换的是交付时间，不是日常体验；常挂着跑，额度一周就见底。
- **Work 和 Codex 共用一份额度，Office 插件也扣这份。** 排产的时候按一份算，别按三份算。
- **Pro 三档都是月付，不能年付。** 想靠年付摊薄单价这条路不存在，试错成本正好锁在一个月。
- **Free 和 Go 不在这次开放名单里。** 名单只列了 Plus、Pro、Enterprise、Edu，名单外的档位什么时候跟上，官方没说。
- **Ultrafast 要美国境内推理。** 节点落点不在美国，这一档拿不到，换机场不解决，只能换线路。
- **别拿 Sol 的价套 Astra 的账。** 单价差四倍，超量之后账单是按 Astra 的价补的，不是按 Sol。
- **代充和车位是两种交付。** 车位省心但账号不属于你，代充贵但订阅在你自己号上；问清交付方式再付款，比事后找回账号省事得多。

## FAQ

### GPT-6.2 Astra 在普通 ChatGPT 里能用吗？

不能。6.2 只进了 Work 和 Codex 两个视图，普通 Chat 里 Pro 及以上拿到的是 GPT-6 Pro，由 GPT-6 Astra 驱动。想在聊天框里点名 6.2，官方目前没有这个入口。

### Plus 和 Pro 的差别到底在哪？

三处：额度、窗口、Ultrafast。Plus 有 5 小时窗口，Pro 没有；Pro 100 的 Work/Codex 额度比 Plus 高一档，Pro 200 再高一档并首次拿到 Sol 的 Ultrafast，Pro 500 拿满并额外有 Astra 的 Ultrafast。功能上三者都能进 Work 和 Codex，差的是能跑多久。

### Ultrafast 值不值得为它升档？

只看交付压力。它最快约 4.5 倍速，但按标准档 6 倍扣额度，属于应急档。天天赶交付、时间比额度贵的，Pro 200 的 Sol 极速是这一代最有性价比的升级；日常修修补补的，这笔钱花得看不见回报。

### 国内买 Plus，代充和车位怎么选？

先看账号归属。车位是平台交付的成品位，便宜、开通快，但账号不属于你；代充是把订阅充到你自己号上，贵一截，账号始终是自己的。已经养了很久的号、里面有工作记录和自定义指令的，我不建议为了省一百多块去换车位。

### 按量 API 和包月哪个划算？

看调用频率。一天几十次的轻量用法，包月加套餐额度更省心；一天上百次、且以写代码为主，按量走 Sol（输入 2 美元、输出 10 美元每百万）比包月更容易控成本。混合用法最划算：Pro 的等额 API 额度跑批处理，订阅额度跑交互。

### GPT-6.2 会替代 GPT-6 Astra 吗？

目前没有。官方给的位置是并列：6.2 Astra 是新的旗舰，GPT-6 Astra 仍在 Pro 500 的 Ultrafast 支持列表里，也仍是聊天框里 GPT-6 Pro 的底座。换代口径以官方公告为准，别按型号数字大小自己推。
